# Hono Commerce Brand Assets

The mark represents a commerce gateway: two folded store or parcel forms interlock into an abstract `H`, while the central crossing suggests movement between stores, orders, and customers.

## Assets

- `hono-commerce-mark.svg`: primary indigo and violet mark for light or neutral surfaces.
- `hono-commerce-mark-mono.svg`: single-color mark for stamps, masks, tiny monochrome contexts, and print.
- `hono-commerce-login-visual.svg`: static decorative visual for the desktop auth panel. Hide it from assistive technology when adjacent auth copy already provides the page meaning, and do not render it on mobile.

## Usage

- Pair the mark with the text `Hono Commerce` rendered in Plus Jakarta Sans at weight 700; keep the wordmark as live text in product interfaces.
- Keep clear space around the mark equal to at least one quarter of its width.
- Use the simple mark rather than the login illustration below 96 CSS pixels.
- Do not recolor individual folds, rotate the mark, add a containing shape, or place it over visually noisy imagery.
- The minimum recommended digital size is 16 CSS pixels for the monochrome mark and 24 CSS pixels for the primary mark.
